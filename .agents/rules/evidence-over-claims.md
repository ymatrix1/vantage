# Evidence over claims

Vantage exists because agents claim "done" without proof. Its own development follows the same rule.

- Don't say a change works until a test or check that exercises it ran **after** your last edit and passed. Show the command and the relevant output.
- If you couldn't run a check, say so plainly and say why. Don't imply it passed.
- A claim about performance needs a before and after measurement with the same setup.
- A claim about data (counts, rates, formats) needs the query that produced it.
- When a review comment says something was fixed, verify the lines changed. Don't trust the reply text.
